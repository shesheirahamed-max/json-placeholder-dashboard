# Post Dashboard

A responsive and dynamic web dashboard that fetches, displays, edits, and deletes post data using an external REST API.

## 🚀 Features

* **Fetch & Display:** Dynamically renders posts fetched from JSONPlaceholder API into clean, responsive cards.
* **Update Post:** Allows users to edit post titles via a browser `prompt()` and sends a `PUT` request to update the UI without reloading.
* **Delete Post:** Removes post records using a `DELETE` API request and dynamically clears the card from the DOM.
* **Responsive Layout:** Built with CSS Grid to ensure seamless viewing across all device screen sizes.

## 🛠️ Tech Stack

* **HTML5** - Page structure and markup
* **CSS3** - Custom styling and CSS Grid layout
* **JavaScript (ES6+)** - Async/Await, Fetch API, DOM Manipulation
